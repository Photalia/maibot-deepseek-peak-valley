# 梁文峰／梁文谷：DeepSeek 峰谷价格播报

一个略带幽默感的 MaiBot 插件。

它会根据北京时间判断 DeepSeek API 当前处于高峰还是空闲时段，将其分别称为：

- 高峰：**梁文峰**，饮料瓶指标为「五梁液」
- 空闲：**梁文谷**，饮料瓶评估为「梁白开」

> 本项目是非官方社区插件，与 DeepSeek 官方无隶属关系。价格数据来源于 [DeepSeek API 官方价格文档](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。v1.1.0 起，插件会在启动与定时轮询时自动解析官方定价页，价目表不再写死；官方价格变化时无需手动更新插件。

## 功能

- `/峰谷`：实时查询当前时段、V4 Flash／Pro 价格及下一次切换时间。
- `/查询ds价格`：手动查询当前峰谷价格（`/峰谷` 的别名入口）。
- `/checkdsapiupdate`：手动触发一次官方更新检查——抓取官方定价页，交由麦麦（MaiBot 本体）判断是否有值得播报的更新并回复结果；抓取失败时会明确回复失败原因。
- 定时播报：北京时间 `09:00`、`12:00`、`14:00`、`18:00` 自动向配置的 QQ 群推送（周末除外）。

查询命令（`/峰谷`、`/查询ds价格`）的价格展示格式沿用「输入X输出Y缓存Z」的原样写法
（例如高峰 `输入3输出9缓存0.1`），价格数值来自动态解析缓存；`/checkdsapiupdate`
则另走页面动态解析并交由麦麦判断播报。
- 周末全天低谷价：自 2026-08-23 00:00 起，周六、周日全天按低谷价计费，播报自动适配。
- 动态定价解析：从官方定价页自动读取模型版本号与价格，缓存并比对。
- 官方变更播报：检测到模型版本号或价格变化时，交由 MaiBot 本体（麦麦）总结后播报。
- 双层防刷：同时限制同一用户和同一聊天流的查询频率。
- 持久化去重：重启不会重复发送已经成功推送的切换通知。
- 独立失败重试：某个目标群发送失败时，只重试失败群，不重复轰炸成功群。
- 日常查询零 LLM：`/峰谷` 与定时播报不调用 AI，仅官方变更播报才会唤醒麦麦总结。

## 官方峰谷时段

北京时间：

| 时段 | 名称 | V4 Flash（输入／输出／缓存命中） | V4 Pro（输入／输出／缓存命中） |
|---|---|---|---|
| 09:00–12:00、14:00–18:00 | 梁文峰 | 3／9／0.1 元 | 9／27／0.3 元 |
| 其余时间 | 梁文谷 | 1.5／4.5／0.05 元 | 4.5／13.5／0.15 元 |

价格单位均为 **每百万 tokens，人民币**。

## 安装

### 插件广场

在 MaiBot 插件广场搜索「DeepSeek 峰谷价格播报」并安装。

### 手动安装

在 MaiBot 的 `plugins` 目录执行：

```bash
git clone https://github.com/Photalia/maibot-deepseek-peak-valley.git local_deepseek-peak-valley
```

随后重启 MaiBot。插件要求：

- MaiBot `>= 1.1.4`
- MaiBot Plugin SDK `>= 2.5.0`

## 配置

MaiBot 可根据插件配置模型自动生成 `config.toml`。也可以手动复制示例：

```bash
cp config.example.toml config.toml
```

主要配置：

```toml
[plugin]
enabled = true
config_version = "1.1.0"

[schedule]
enabled = true
# 需要主动播报的 QQ 群号；留空时只启用 /峰谷。
target_group_ids = ["123456789", "987654321"]
# 切换后允许补发及重试的秒数。
grace_seconds = 120

[fetch]
# 是否动态解析官方定价页（v1.1.0 起默认开启，价目表不再写死）。
enabled = true
# 定时轮询抓取间隔（秒）。默认 12 小时。
poll_interval_seconds = 43200
# 单次抓取官方页的超时（秒）。
fetch_timeout_seconds = 10
# 连续抓取失败达到该次数后才推送一次告警，避免刷屏。
alert_after_failures = 3

[rate_limit]
# 同一用户 30 秒内只响应一次。
user_cooldown_seconds = 30
# 同一聊天流 5 秒内只响应一次。
stream_cooldown_seconds = 5
```

冷却期间的重复命令会被静默吞掉，避免「查询太频繁」提示本身成为刷屏内容。

### 周末低谷规则

自 `2026-08-23 00:00` 起，周末（周六、周日）全天按低谷价计费。插件已内置该规则，
周末播报会显示「梁文谷 / 梁白开」并附加「今日为周末，全天按低谷价计费」提示；
从周五 18:00 至下周一 09:00 之间不再触发峰谷切换播报。

## 定时逻辑

工作日切换时间为：

- `09:00`：进入梁文峰
- `12:00`：进入梁文谷
- `14:00`：进入梁文峰
- `18:00`：进入梁文谷

周末（周六、周日，自生效日起）全天为梁文谷，不做峰谷切换；下一次高峰出现在下周一 `09:00`。

插件使用固定 UTC+8 计算北京时间，不依赖宿主机当前时区。每个群的发送状态分别记录在插件 `data/state.json` 中；定价缓存记录在 `data/pricing.json` 中。

## 与睡眠／宵禁插件共存

如果另一个插件会在睡眠期间全局拦截入站命令或出站消息，那么 `09:00` 定时播报或睡眠期间的 `/峰谷` 也可能被它拦截。这属于拦截插件的全局策略；请在对应插件中为 `/峰谷` 和本插件的系统播报配置白名单。

另外，本插件的官方变更播报通过 `maisaka.proactive.trigger` 唤醒麦麦总结。若宿主在特定时段禁用了麦麦的主动发言，此播报可能不会落地；此时插件会回退为直接发送差异文本。

本仓库不会自动修改其他插件。

## 隐私与网络

- 不读取聊天历史，不收集用户数据。
- 仅在启动与定时轮询时请求 DeepSeek 官方定价页，解析价格与版本号。
- 日常 `/峰谷` 与峰谷切换播报不调用任何 LLM。
- 仅当检测到官方价格／版本变更时，才唤醒麦麦做一次总结播报。
- 其余能力仅使用 MaiBot 的聊天流查询、文本发送与 Maisaka 上下文能力。
